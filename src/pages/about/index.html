About {{ site_brand }}

Free GIF and image tools that run in your browser instead of on someone else's server.

What this is

{{ site_brand }} is a small collection of tools for editing GIFs and images: adding captions, cropping, resizing, converting between formats, and turning video clips into GIFs. Everything is free, nothing requires an account, and exports carry no watermark unless you choose to add one.

Why it works in the browser

Most online media tools work by uploading your file to a server, processing it there, and sending the result back. That approach is simple to build, but it means every file you touch is copied to someone else's computer, and it puts a hard ceiling on file size because somebody has to pay for the bandwidth.

Modern browsers can do this work themselves. So on {{ site_brand }}, the editing happens on your own device — your file is read locally, processed locally, and saved locally. It is faster for small files because nothing has to be uploaded, and it means we never hold a copy of your work.

The honest trade-off: because the work runs on your device, a very large GIF is limited by your available memory rather than by an upload cap, and a slow device will encode more slowly than a server would. We would rather be straightforward about that than claim the approach has no downsides.

Two features do use a server, because they cannot work any other way, and both are opt-in: AI motion tracking and sharing a GIF by link. The privacy policy sets out exactly what each one sends.

The tools

  • GIF Editor — captions, motion keyframes, object tracking, crop and compression
  • Video to GIF — trim a clip and convert it
  • GIF Maker — build an animation from still images
  • GIF Resizer and GIF Cropper
  • Image Editor — captions, title bars, filters, crop and resize
  • Photo Converters — JPG, PNG, WebP, HEIC and SVG

Who makes it

{{ site_brand }} is built and maintained by one person as an independent side project. It is funded by the ads shown on some pages, which is what keeps it free to use and free of signup walls.

Being a one-person project also sets expectations honestly: fixes and new tools arrive when time allows, and the best way to get a bug looked at is to report it.

Found a problem?

Bug reports are genuinely useful — a broken tool is invisible to us until someone says so. The Report an issue button in the site header sends a report directly, or see the contact page.
